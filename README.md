## 📌 Overview
FitGym is a vanilla JavaScript web application designed to act as a centralized command center for personal fitness. It allows users to track their workouts, monitor daily habits, calculate precise nutritional needs, and visualize muscle recovery—all within a dynamic, single-page interface without requiring a backend database.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom variables, Flexbox/Grid, Animations)
* **Logic:** Vanilla JavaScript (ES6+)
* **Data Persistence:** Browser `localStorage` API
* **Icons & UI:** FontAwesome, Google Fonts (Poppins)

## 🚀 Core Features

### 1. Daily Command Center
* **Vitals Tracking:** Log daily steps, sleep hours, and overall mood.
* **Hydration & Recovery:** Interactive water intake tracker and a built-in customizable rest timer.
* **Gamification:** A robust "Trophy Room" achievement system that visually rewards consistency and PRs.

### 2. Dynamic Workout & Lifts
* **Muscle Recovery Heatmap:** Visual click-to-cycle status (Fresh, Sore, Fatigued) for major muscle groups.
* **1RM Calculator:** Instantly estimates One-Rep Max based on weight and reps lifted.
* **Automated Routine Generator:** Select a muscle focus (e.g., Chest, Back, Legs) to instantly generate a table of suggested exercises, sets, reps, and rest times.

### 3. Diet & Medical Profiler
* **Advanced Biometric Calculators:** Calculates Total Daily Energy Expenditure (TDEE) and BMI based on age, weight, height, and activity level.
* **Macro Estimation:** Automatically generates suggested Protein, Carb, and Fat targets based on the TDEE output.
* **Logging System:** Manage grocery lists, daily meals, and specific medical/allergy profiles.

### 4. Coach Hub (Simulation)
* **Media Feed:** UI layout for educational fitness videos.
* **Direct Messaging:** A simulated chat interface designed for real-time coach-to-trainee communication.
